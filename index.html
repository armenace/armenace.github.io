How I work

AI writes fast. Taste and checking are my job. Every page goes through the same four passes.

  1. Build

    I describe the page in plain words and build it with Claude Code, using design rules that ban the generic AI look.

  2. Critique

    A design review pass hunts for weak hierarchy, cramped spacing and confusing copy. Then I fix what it finds.

  3. Polish

    Real button text, hover and focus states, empty states, and the corners nobody else bothers to check.

  4. Test

    Accessibility audit, speed check, then I click through every screen size myself before calling it done.
